# 设计与创作说明

这是一个独立的公开博客模板，使用虚构英文财经刊物 **Margin & Measure** 展示排版。它不包含原私人博客的研究文章、简历、奖项、联系方式或部署域名。

## 设计语言

暖纸底色 `#f6f3ed`，炭黑正文 `#2c2b27`，胡桃色与灰绿色作为重点色。英文衬线标题搭配系统无衬线正文；页面使用细线、低对比度色块与克制的阴影建立层次。

正文为 16px / 1.65，段间距 10px。桌面目录独立于正文列；手机目录可以折叠。代码块限制高度，长代码和宽表格在自身区域滚动。图片预留宽高，避免加载时打乱目录定位。

首页区分编辑精选和按日期排列的最近文章，同一篇文章可以同时出现。归档、短札记、搜索、关于页和 404 页面均包含在模板中。

## 创作过程

主题经过多轮真实页面排版调整：先确定材质与层次，再压缩过大的字距和留白，最后用完整文章检验阅读效果。当前模板进一步抽离私人内容，并重新设计可编辑的财经 SVG 配图。

示例内容由 AI 辅助原创，包括利率与债券、现金流、分散投资、通胀，以及两篇短札记。数据全部是明确说明假设的教学示例，不是实时行情、投资建议或业绩记录。文中引用链接提供背景阅读，不表示对方为本站背书。

建筑主图来自 AI 辅助设计。财经图表为代码生成的 SVG，源文件随模板提供。README 效果图来自实际运行页面截图，而非概念效果图。

## 使用与定制

完整的逐步操作、图片路径和页面配置对应表见 [写作与定制指南](WRITING.zh-CN.md)。

1. 点击 GitHub 的 **Use this template** 创建自己的仓库。
2. 使用 Node.js 22，运行 `npm ci` 和 `npm run dev`。
3. 修改 `content/site-config.json` 设置站名、文案与联系信息。
4. 在 `content/articles/` 添加 Markdown，并在 `content/article-meta.json` 添加同名元数据。
5. 使用 `Essay` 作为长文类型，`Journal` 作为札记类型；分类和标签可自定义。
6. 修改 `app/globals.css` 的色彩变量和布局；图片放入 `public/images/`。
7. 发布前运行测试、类型检查、构建和静态导出校验。

模板不会自动公开站点：workflow 默认只检查代码，需显式设置 `PAGES_ENABLED=true` 才会发布。GitHub 项目站点还需设置 `NEXT_PUBLIC_BASE_PATH=/仓库名`；自定义域名或根站点留空。详细步骤见根目录 README。
